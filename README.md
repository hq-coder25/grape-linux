# 🍇 GRAPE LINUX
### Your hardware. A new beginning.

**Native Linux on real iPhone hardware. A proof of concept you can see.**

Grape Linux is a hardware-first operating-system initiative built around a powerful idea: **valuable computing hardware deserves a longer, more useful life.**

We have demonstrated **Debian 13 ARM64 booting on a physical iPhone 8 Plus powered by Apple's A11 chip**, with a Linux kernel and a graphical Linux environment. That is the foundation behind Grape Linux: actual device-level engineering, captured in our development evidence and on-device demonstrations.

## We've made Linux run on an iPhone.

Our proof-of-concept engineering includes:

- **Physical iPhone 8 Plus / A11 Linux boot**
- **Debian 13 ARM64** userspace
- An experimental **Linux 5.19-based kernel**
- **Phosh / Phoc** graphical Linux interface
- Live graphical output and low-level hardware diagnostics
- Device hardware investigation, including power telemetry and storage interfaces

**This is where the story begins — with a real device, real Linux, and real results.**

## A second life for remarkable hardware

Imagine the value still locked inside retired and underused phones: a capable processor, a sharp display, and a compact form factor.

**Grape Linux is about turning that potential into purpose.**

- **Personal computing:** A pocket-sized Linux platform.
- **Learning:** Hands-on opportunities for Linux, ARM64, and operating-system development.
- **Research:** A distinctive platform for low-level hardware experimentation.
- **Device longevity:** New possibilities for compatible aging hardware.
- **Sustainability:** More useful years from electronics already manufactured.

## The next chapter

Building on our proven native Linux boot, we're shaping an experience where a compatible iPhone can **power directly into Linux**, with a natural graphical workflow and the tools of an open computing platform.

Our vision is simple: **pick up the device, power it on, and give it a new purpose.**

The underlying hardware has already shown what it can do. We're building the experience around that achievement.
