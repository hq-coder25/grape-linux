# Grape Linux recordkeeping standard

Adopted: 2026-10-28. Event time not independently captured.

This public project preserves major and minor milestones, dated journal entries, development evidence, revisions and releases.

- Add an entry for every substantive change, test, discovery, new feature, regression and correction.
- State the date, time and time zone where known. Do not invent missing timestamps.
- Distinguish owner reports, tested behavior, evidence and future objectives.
- Archive superseded history with dated addenda rather than silently changing claims.
- Keep README links up to date and each component documented.
- Remove confidential credentials and legally restricted personal or third-party data where necessary, with a sanitized audit note.

A reported completion percentage is an estimate until a coverage inventory and repeatable validation method have been established.
